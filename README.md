# 居民都市 v3：地塊對人＋積木編輯器

## 開啟
- City_Plot_Editor.html：2D 積木編輯、居民配置、3D 預覽。
- People_City_MToon.html：3D 展示頁。
- 兩個檔案依賴皆已內嵌，可直接開啟；3D 需支援 WebGL。編輯與展示共用 city.json。

## 操作
1. 在編輯器選土地／道路／建築／特殊建築，再選模板。
2. 點空白網格放置。放置旋轉90°切換方向；選取模式可選既有地塊。
3. 選取地塊後可旋轉、刪除、設為預設中心、勾選居民（0～20人）。
4. 編輯視窗16×16格，方向按鈕移動視窗，不限制於此範圍。
5. 匯出都市 JSON。展示頁可手動匯入同一檔案。
6. 放到靜態網站時，兩個 HTML 與 city.json 放在同資料夾，會自動讀取 JSON。

## 資料
- 內含100位虛構居民、91塊示範地塊，100人已分配。空地塊可以0人。
- 土地／道路／一般建築為1×1；特殊建築占地為模板指定的整數尺寸，旋轉會交換長寬。
- 地塊使用 residents 保存人物 ID 陣列。一個人只能分配給一個地塊，取消勾選後可轉移。
- 新增人物可編輯 city.json 的 people 陣列，再匯入。頭像 avatar 可為圖片網址。
- 編輯器防止重疊、重複人物、超過20人與失效中心點。
- 復原最多30步；尚未匯出會在離開時提示。請自行匯出保存，沒有後端自動寫入。
- 舊版一人一地塊 JSON 不相容；此版使用 version:3。

## 模板
共62種：土地10、道路12、一般建築12、特殊地標28。
道路有市區／鄉村／土路／橋梁，分直線、十字、轉彎，可旋轉。
地標採用程序化簡化積木造型，並非精密或等比例復刻；模板名稱見 model.js。
加拿大廣場先以高樓廣場表示；臥佛寺以寺院及臥佛組合表示。

## 效能與驗證
3D 保留距離巡覽中心16格內最近36個地塊，遠處卸載、釋放幾何與招牌紋理；MToon材質共用。
目前並無全城遠景 LOD，也沒有自動調整橋梁與路面高差、河岸銜接。
已驗證資料對應、20人上限、占地重疊；62個模板在0°和90°共124次幾何建構通過。
已在瀏覽器確認編輯器載入、搜尋與居民配置介面。此環境不能建立WebGL，3D畫面未完成視覺驗證。
